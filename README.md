# Uy Studiyasi

Brauzerda ishlaydigan 3D uy konstruktori. Three.js asosida, serversiz, bitta `index.html` fayl.

## Imkoniyatlar

- Sichqoncha bilan aylantirish, siljitish va yaqinlashtirish
- Uy o'lchami, qavatlar, tom turi, deraza va eshiklarni o'zgartirish
- Ichkarida birinchi shaxs ko'rinishida sayr qilish (W A S D)
- 18 xil jihoz: qo'shish, sudrash, burish, rangini va kattaligini o'zgartirish
- Kun va tun, o'lcham chiziqlari, Ctrl+Z / Ctrl+Y

## Ishga tushirish

`index.html` faylni brauzerda oching. Three.js va shriftlar internetdan yuklanadi, shuning uchun internet kerak.

## GitHub Pages

Repository sozlamalarida **Settings → Pages → Deploy from a branch → main / (root)** ni tanlang.
